# FutureX Ignite

Build a long-scroll, premium, futuristic technology event landing page for AT FUTUREX — AI • CODE • CREATE, organized by Anandathirtha Pre University College.

Visual Theme:
- Deep navy/black background with neon blue, cyan, magenta, electric green, and orange accents.
- Futuristic HUD elements, glowing borders, digital particles, subtle grid patterns, and holographic interfaces.
- Smooth animations (using Lucide icons, Framer Motion / GSAP scroll triggers, microinteractions, and particle effects).

Sections:
1. Hero Section: 'AT FUTUREX — AI • CODE • CREATE', supporting text 'A one-day technology experience for Class X students', cinematic futuristic visual with AR glasses/holographic code aesthetic, prominent registration CTA and countdown timer.
2. About the Event: Hands-on technology experience, interactive digital displays, animated digital circuitry.
3. 3 Workshop Cards (Visually distinct, theme-colored with realistic tech visuals):
   - Intro to Arduino (Hardware Programming, cyan/electric blue, realistic UNO board, LEDs, circuits)
   - AI & Excel Mastery (AI & spreadsheet tools, neon green, data dashboards, AI analytics)
   - Prompt Engineering & Website Making (Web design/AI prompts, neon purple & magenta, modern web coding workspace)
4. Learning Experience Journey: 4 interactive animated steps (Learn, Build, Explore, Create).
5. Event Benefits Grid: 6 Hours Duration, Campus Lunch Provided, Course Certificate, Top Participant Prizes, Exclusive Anandathirtha PU College Discount.
6. Registration Section: Class X eligibility, strictly 30 seats limit, Google Forms registration CTA, scannable high-res QR code, glowing button.
7. Bring Along: School ID card photocopy, Aadhaar copy checklist with clear tech badges/icons.
8. Venue Section: Anandathirtha PU College Campus with address, directions, stylized campus imagery, and map area.
9. Final CTA: 'Tech Today, A Brighter Tomorrow' with final 'Register Now' trigger and sleek footer.

Ensure high visual polish, realistic curated imagery for tech/hardware/dashboards (via Unsplash tech photos), glowing glassmorphism HUD cards, sound/visual toggles or interactive effects, and complete responsiveness across mobile, tablet, and desktop.
